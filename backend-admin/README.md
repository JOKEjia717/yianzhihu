# 社区养老管理系统

基于Vue 3 + Element Plus的现代化社区养老管理系统，包含子女管理、志愿者管理、院长管理、可视化大屏等功能模块。

## 功能特点

- 响应式布局，支持多端设备访问
- 可视化大屏，直观展示老人数量、性别比例、年龄分布等重要数据
- 子女管理系统，方便记录子女信息和探访记录
- 志愿者管理系统，包含基本信息、服务评分、证书统计等功能
- 院长管理系统，采用卡片式布局，展示绩效评估
- 基于Element Plus组件库，UI风格统一美观

## 技术栈

- Vue 3
- Vue Router
- Pinia
- Element Plus
- ECharts
- Axios

## 项目运行

```bash

npm install

# 开发环境运行
npm run serve

# 生产环境构建
npm run build

# 代码检查
npm run lint
```

## 模块说明

1. **可视化大屏**：展示社区养老整体运营数据，包括老人数量、性别比例、年龄分布、护理需求等。
2. **子女管理**：记录老人家属信息，包括联系方式、探访频率、缴费方式等。
3. **志愿者管理**：记录志愿者基本信息、专业技能、服务评分等，并提供志愿者数据统计分析。
4. **院长管理**：以卡片形式展示管理层信息，包括基本资料、专业背景、绩效评估等。
